# การเชื่อม LINE แจ้งเตือนจุดความร้อนใกล้สถานที่กำจัดขยะ (รัศมี 500 ม.)

> **องค์ความรู้ (KM) จากการติดตั้งใช้งานจริง** · ปรับปรุงล่าสุด 27 พฤศจิกายน 2569
> โค้ดที่ใช้: [`apps-script/landfill-fire-line-alert.gs`](../apps-script/landfill-fire-line-alert.gs) · ใช้คู่กับหน้า [Fire Radar](../fireRadar.html)

## สรุปสั้น

- ระบบตรวจจุดความร้อนจากดาวเทียมเองทุก 30 นาที ถ้าพบจุดที่ห่างจากสถานที่กำจัดขยะ**ไม่เกิน 500 เมตร** จะส่งข้อความเข้ากลุ่ม LINE ให้อัตโนมัติ ไม่ต้องมีใครเปิดหน้าเว็บ
- ส่งผ่าน **LINE Messaging API** ของบัญชี LINE Official Account เพราะ **LINE Notify ปิดบริการแล้วตั้งแต่ 31 มีนาคม 2568**
- สคริปต์ทำงานบน **Google Apps Script** ไม่มีค่าเซิร์ฟเวอร์ ค่าใช้จ่ายจะมีก็ต่อเมื่อส่งข้อความ LINE เกินโควตาฟรี
- ใช้ข้อมูลและเกณฑ์ชุดเดียวกับหน้า Fire Radar ผลการแจ้งเตือนจึงตรงกับที่เห็นบนแผนที่

## ระบบทำงานอย่างไร

**การแจ้งเตือน** (ทำงานเองทุก 30 นาที)

1. ทริกเกอร์ของ Apps Script เรียกฟังก์ชัน `checkLandfillFireRisk`
2. สคริปต์ดึงจุดความร้อนจาก NASA FIRMS (เครื่องวัด VIIRS บนดาวเทียม NOAA-20 และ NOAA-21) ผ่านระบบส่วนกลางชุดเดียวกับหน้า Fire Radar
3. ดึงรายชื่อสถานที่กำจัดขยะ สคพ. 1–16 จากไฟล์ `landfill_sites_epo1-16.json` รวมกับ Google Sheet
4. หาจุดความร้อนที่ห่างจากสถานที่กำจัดขยะไม่เกิน 500 ม. และยังไม่เคยแจ้ง
5. รวมทุกแห่งที่พบในรอบนั้นเป็นข้อความเดียว แล้วส่งเข้ากลุ่ม LINE
6. จำจุดที่แจ้งแล้วเพื่อไม่ให้แจ้งซ้ำ ถ้าส่งไม่สำเร็จจะลองใหม่ในรอบถัดไป

**การหารหัสกลุ่ม** (ใช้ตอนติดตั้งเท่านั้น)

พิมพ์ "รหัสกลุ่ม" ในกลุ่ม → LINE ส่งข้อความต่อไปที่ Webhook (Apps Script ฟังก์ชัน `doPost`) → บอทตอบรหัสกลุ่มกลับเข้ากลุ่ม

**ตัวอย่างข้อความแจ้งเตือน** (ข้อมูลสมมติ)

```text
🔥 พบจุดความร้อนใกล้สถานที่กำจัดขยะ
ในรัศมี 500 ม. · 1 แห่ง · จุดความร้อนใหม่ 2 จุด

📍 1) สถานที่กำจัดขยะมูลฝอย อบต.ตัวอย่าง
จ.นครราชสีมา (สคพ.11)
🔥 2 จุด · ใกล้สุด 180 ม. · ล่าสุด 27 พ.ย. 13:42 น. (NOAA-20)
https://www.google.com/maps?q=15.0,102.0

ℹ️ จุดความร้อนจากดาวเทียม NASA FIRMS (VIIRS) ตำแหน่งคลาดเคลื่อนได้ราว 375 ม. ควรตรวจสอบในพื้นที่
🗺️ https://thesiamtimes.com/fireRadar.html?epo=11&sat=all
```

## สิ่งที่ต้องเตรียม

| สิ่งที่ต้องมี | ใช้ทำอะไร |
|---|---|

| บัญชี Google | ใช้สร้างโปรเจกต์ Google Apps Script (ฟรี) |
| กลุ่ม LINE ที่จะรับแจ้งเตือน | ต้องเป็นสมาชิกที่เชิญบอทเข้ากลุ่มได้ |
| ไฟล์โค้ด | [`apps-script/landfill-fire-line-alert.gs`](../apps-script/landfill-fire-line-alert.gs) ใน repo นี้ |

## ขั้นตอนการติดตั้ง

### ขั้นที่ 1 สร้างบัญชี LINE Official Account และเปิด Messaging API

1. เข้า <https://manager.line.biz> แล้วสร้างบัญชี LINE Official Account เริ่มจากแผนฟรีได้
2. ใน LINE Official Account Manager ไปที่ **ตั้งค่า (Settings) > Messaging API** กด **Enable Messaging API**
3. ระบบจะให้เลือกหรือสร้าง **Provider** ให้ใช้ชื่อหน่วยงาน เพราะเลือกแล้วย้ายภายหลังไม่ได้

### ขั้นที่ 2 ออก Channel access token

1. เข้า <https://developers.line.biz/console> เลือก Provider แล้วเลือก channel ของบัญชี
2. ไปที่แท็บ **Messaging API** เลื่อนลงล่างสุดถึงหัวข้อ **Channel access token (long-lived)** กด **Issue**
3. คัดลอกด้วย**ไอคอนคัดลอก (📋)** ข้าง token อย่าใช้วิธีลากคลุมข้อความ เพราะบนแท็บเล็ตหรือมือถือมักคัดลอกได้ไม่ครบ หรือมีการขึ้นบรรทัดใหม่ติดมา

> **ตรวจว่าคัดลอกถูก:** token ยาวราว 170 ตัวอักษรและมักลงท้ายด้วย `=` อย่าสับสนกับ **Channel secret** ในแท็บ Basic settings ซึ่งยาว 32 ตัว ใช้แทนกันไม่ได้

> ⚠️ **token เทียบเท่ารหัสผ่านของบอท** ใครได้ไปก็ส่งข้อความในนามบอทได้ อย่าแคปหน้าจอที่เห็น token และอย่าส่งต่อในแชท ถ้าหลุดให้ทำตามหัวข้อ [ความปลอดภัย](#ความปลอดภัย)

### ขั้นที่ 3 อนุญาตให้บอทเข้ากลุ่ม

ค่าเริ่มต้นของบัญชีใหม่**ไม่อนุญาต**ให้บอทเข้ากลุ่ม ถ้าไม่เปิดก่อน เชิญบอทเข้ากลุ่มแล้วบอทจะออกเองทันที

1. LINE Developers Console > แท็บ **Messaging API** > หัวข้อ **LINE Official Account features**
2. ที่ **Allow bot to join group chats** กด **Edit** ระบบจะพาไปหน้า LINE Official Account Manager
3. เปิดตัวเลือก**ยอมรับคำเชิญเข้าร่วมกลุ่มหรือแชทรวม** (Accept invitations to groups or multi-person chats) แล้วบันทึก
4. กลับมาที่ Console แล้วรีเฟรช ต้องขึ้นว่า **Enabled**
5. แนะนำให้ปิด **Auto-reply messages** ด้วย: กด **Edit** ในหน้าเดียวกัน แล้วปิด**ข้อความตอบกลับอัตโนมัติ** ใน **ตั้งค่าการตอบกลับ (Response settings)** ไม่อย่างนั้นบอทจะตอบอัตโนมัติทุกครั้งที่มีคนพิมพ์

### ขั้นที่ 4 ติดตั้งสคริปต์ใน Google Apps Script

1. เข้า <https://script.google.com> > **New project** แล้วตั้งชื่อโปรเจกต์ เช่น "แจ้งเตือนไฟบ่อขยะ LINE"
2. ลบโค้ดตัวอย่าง วางโค้ดจาก `apps-script/landfill-fire-line-alert.gs` ทั้งไฟล์ แล้วกด **Save**
3. ไปที่ **Project Settings** (รูปเฟือง) > **Script properties** > **Add script property**
   - Property: `LINE_CHANNEL_ACCESS_TOKEN` (ต้องสะกดตรงทุกตัว ไม่มีช่องว่าง)
   - Value: token จากขั้นที่ 2
4. กลับไปหน้าโค้ด เลือกฟังก์ชัน **`checkSetup`** แล้วกด **Run**
   - ครั้งแรกระบบจะขอสิทธิ์: กด **Review permissions** > เลือกบัญชี > **Advanced** > **Go to … (unsafe)** > **Allow** เป็นขั้นตอนปกติของสคริปต์ที่เขียนเอง
5. ดู Execution log บรรทัดแรกต้องขึ้นว่า `OK LINE token: บัญชี …`

### ขั้นที่ 5 Deploy เป็น Web app

1. กด **Deploy** > **New deployment** > กดรูปเฟืองข้าง Select type แล้วเลือก **Web app**
2. ตั้งค่า:
   - **Execute as:** Me
   - **Who has access:** **Anyone** (ต้องเป็น Anyone เท่านั้น ถ้าเลือก "Anyone with Google account" LINE จะเรียกสคริปต์ไม่ได้)
3. กด **Deploy** แล้วคัดลอก **Web app URL** ที่ลงท้ายด้วย `/exec`

### ขั้นที่ 6 ตั้ง Webhook

1. LINE Developers Console > แท็บ **Messaging API** > **Webhook settings** > **Webhook URL** > กด **Edit** วาง URL จากขั้นที่ 5 แล้วกด **Update**
   (จะใส่ใน LINE Official Account Manager > ตั้งค่า > Messaging API > Webhook URL > Save แทนก็ได้)
2. เปิดสวิตช์ **Use webhook** ให้เป็นสีเขียว
3. **ปิด Webhook redelivery** ไว้ เพราะ LINE จะเข้าใจว่าส่งไม่สำเร็จทุกครั้ง (ดูข้อ 4) ถ้าเปิดไว้ LINE จะส่งซ้ำไปเรื่อย ๆ
4. ถ้ากดปุ่ม **Verify** จะขึ้นข้อความ `The webhook returned an HTTP status code other than 200.(302 Found)` **เป็นเรื่องปกติ** เพราะ Apps Script ตอบกลับแบบ redirect แต่ข้อความถึงสคริปต์และสคริปต์ทำงานครบแล้ว

### ขั้นที่ 7 หารหัสกลุ่ม

1. เชิญบัญชี LINE OA เข้ากลุ่ม บอทจะตอบรหัสกลุ่มให้ทันที
2. หรือพิมพ์คำใดคำหนึ่งต่อไปนี้ในแชท **โดยพิมพ์คำนั้นอย่างเดียว**:

   | พิมพ์ | พิมพ์ในกลุ่ม | พิมพ์ในแชทส่วนตัวกับบอท |
   |---|---|---|
   | `รหัสกลุ่ม` · `รหัส` · `id` · `group id` · `groupid` | ได้รหัสกลุ่ม (ขึ้นต้นด้วย **C**) | ได้รหัสบุคคล (ขึ้นต้นด้วย **U**) |

3. ถ้ามีคำอื่นปน เช่น "ขอรหัส" บอทจะไม่ตอบ ระบบตั้งใจไม่ให้บอทตอบข้อความทั่วไปในกลุ่ม
4. การตอบรหัสใช้ reply message จึง**ไม่เสียโควตา**

### ขั้นที่ 8 ตั้งผู้รับและเปิดใช้งาน

1. Script properties > เพิ่ม `LINE_TO` = รหัสกลุ่มจากขั้นที่ 7 ถ้ามีผู้รับหลายรายให้คั่นด้วยจุลภาค เช่น `Cxxxx,Uyyyy`
2. Run **`checkSetup`** ต้องเห็นชื่อกลุ่ม จำนวนสมาชิก และโควตาที่ใช้ต่อการแจ้งเตือน 1 ครั้ง
3. Run **`sendTestMessage`** ข้อความทดสอบต้องขึ้นในกลุ่ม
4. (แนะนำ) เพิ่ม `ALERT_EPOS` = `11` ถ้าต้องการเฉพาะพื้นที่ สคพ.11 จะช่วยประหยัดโควตา
5. Run **`installTriggers`** ระบบจะเริ่มตรวจเองทุก 30 นาที แล้ว Run `checkSetup` อีกครั้ง บรรทัดสุดท้ายต้องขึ้นว่า `OK ทริกเกอร์: ตรวจเองทุก 30 นาที`

รอบแรกหลังติดตั้งจะแจ้งจุดที่พบใน 24 ชั่วโมงที่ผ่านมาทั้งหมด จากนั้นแจ้งเฉพาะจุดใหม่ ถ้าไม่มีจุดความร้อนในรัศมี 500 ม. จะไม่มีข้อความส่งมา

## ค่าที่ตั้งได้ (Script properties)

| ชื่อ | จำเป็น | ความหมาย | ค่าเริ่มต้น |
|---|---|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | ✅ | token จากขั้นที่ 2 | – |
| `LINE_TO` | | รหัสผู้รับ: กลุ่ม (C…) ห้องแชท (R…) หรือบุคคล (U…) คั่นด้วยจุลภาค | ไม่ใส่ = ส่งถึงทุกคนที่เป็นเพื่อนกับบัญชี (broadcast) |
| `ALERT_EPOS` | | สคพ. ที่ต้องการแจ้ง เช่น `11` หรือ `11,12` | ทั้ง 16 สคพ. |
| `ALERT_SATELLITES` | | ดาวเทียมที่ใช้ เช่น `N20` หรือ `N20,N21` | ทุกดวง |
| `ALERT_MAX_AGE_HOURS` | | แจ้งเฉพาะจุดที่ดาวเทียมตรวจพบภายในกี่ชั่วโมง | 24 |

แก้ค่าเหล่านี้แล้ว**มีผลทันที ไม่ต้อง deploy ใหม่**

## ฟังก์ชันที่กด Run ได้

| ฟังก์ชัน | ใช้ทำอะไร | ใช้โควตา |
|---|---|---|
| `checkSetup` | ตรวจ token ผู้รับ โควตาคงเหลือ แหล่งข้อมูล และทริกเกอร์ | ไม่ใช้ |
| `previewAlert` | แสดงข้อความที่จะส่งจากข้อมูลขณะนี้ใน log โดยไม่ส่งจริง | ไม่ใช้ |
| `sendTestMessage` | ส่งข้อความทดสอบถึงผู้รับใน `LINE_TO` | 1 ข้อความต่อผู้รับ 1 คน |
| `installTriggers` | ตั้งให้ตรวจเองทุก 30 นาที (Run ซ้ำได้ ไม่สร้างทริกเกอร์ซ้อน) | ไม่ใช้ |
| `removeTriggers` | หยุดการตรวจอัตโนมัติ | ไม่ใช้ |
| `checkLandfillFireRisk` | ตรวจและส่งแจ้งเตือนทันที (ฟังก์ชันเดียวกับที่ทริกเกอร์เรียก) | เฉพาะเมื่อพบจุดใหม่ |
| `resetSentHistory` | ล้างรายการจุดที่แจ้งแล้ว รอบถัดไปจะแจ้งจุดเดิมอีกครั้ง | – |

## โควตาข้อความและค่าใช้จ่าย

- **วิธีนับ:** LINE นับ 1 ข้อความต่อผู้รับ 1 คน การส่งเข้ากลุ่มที่มีสมาชิก 10 คนจึงนับเป็น 10 ข้อความ
- **การแจ้งเตือน:** ระบบรวมทุกแห่งที่พบในรอบเดียวเป็นการส่งครั้งเดียว (ยาวได้สูงสุด 5 กล่องข้อความ แต่นับโควตาเท่ากับส่งครั้งเดียว)
- **การตอบรหัสกลุ่ม:** ไม่ใช้โควตา

แผนของ LINE Official Account ในประเทศไทย (ข้อมูล ณ พฤศจิกายน 2569 จากแหล่งข้อมูลภายนอก ก่อนตัดสินใจให้ตรวจราคาล่าสุดในหน้าแพ็กเกจของ LINE Official Account Manager):

| แผน | ราคา/เดือน (ไม่รวม VAT) | ข้อความ/เดือน |
|---|---|---|
| ฟรี | 0 บาท | 300 |
| Basic | 1,280 บาท | 15,000 |
| Pro | 1,780 บาท | 35,000 |

- **ตัวอย่าง:** กลุ่ม 10 คนบนแผนฟรี แจ้งเตือนได้ราว 30 ครั้งต่อเดือน ช่วงฤดูเผา (ม.ค.–เม.ย.) อาจไม่พอ
- **วิธีประหยัด:** จำกัดพื้นที่ด้วย `ALERT_EPOS` หรือใช้กลุ่มที่มีเฉพาะผู้ปฏิบัติงาน
- **ถ้าโควตาหมด:** LINE จะตอบ HTTP 429 ระบบจะลองส่งใหม่ในรอบถัดไป แต่จุดที่เก่ากว่า `ALERT_MAX_AGE_HOURS` จะไม่ถูกแจ้ง
- **ดูโควตาคงเหลือ:** Run `checkSetup`

## ปัญหาที่พบบ่อยและวิธีแก้

ปัญหาเหล่านี้พบจริงระหว่างการติดตั้ง

| อาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| เชิญบอทเข้ากลุ่มแล้วบอทออกเอง | ยังไม่เปิด Allow bot to join group chats (ค่าเริ่มต้นปิด) | ทำตามขั้นที่ 3 แล้วเชิญใหม่ |
| เปิดสิทธิ์แล้วแต่บอทยังเข้ากลุ่มไม่ได้ | กลุ่มมีบัญชี LINE OA อื่นอยู่แล้ว (กลุ่มหนึ่งมีได้ทีละบัญชี) | ให้บัญชีนั้นออกก่อน หรือใช้กลุ่มใหม่ |
| กด Verify แล้วขึ้น `302 Found` | Apps Script ตอบกลับแบบ redirect | ปกติ ใช้งานต่อได้ |
| พิมพ์ "รหัสกลุ่ม" แล้วบอทเงียบ | ส่วนใหญ่เป็นเพราะ token ไม่ถูกต้อง | Run `checkSetup` ถ้าขึ้น 401 ให้ดูแถวถัดไป |
| `checkSetup` ขึ้น `HTTP 401 Authentication failed` | token คัดลอกไม่ครบ มีช่องว่างติดมา ใช้ Channel secret แทน หรือ token ถูก Reissue ไปแล้ว | Reissue แล้วคัดลอกด้วยไอคอน 📋 ลบค่าเดิมออกให้หมดแล้ววางใหม่ จากนั้น Run `checkSetup` |
| token ผ่านแล้วแต่บอทยังเงียบ | Use webhook ยังปิดอยู่ บอทไม่ได้อยู่ในแชทนั้น หรือพิมพ์คำอื่นปน | ตรวจขั้นที่ 6–7 |
| หน้า Executions ไม่มีแถว `doPost` เลย | ไม่ได้ตั้ง Who has access เป็น Anyone หรือ Webhook URL ผิด | Deploy ใหม่ตามขั้นที่ 5 แล้วใส่ URL ใหม่ |
| ส่งแล้วขึ้น `HTTP 400` | `LINE_TO` ผิด หรือบอทถูกนำออกจากกลุ่มแล้ว | หารหัสใหม่ตามขั้นที่ 7 |
| ส่งแล้วขึ้น `HTTP 429` | โควตาเดือนนี้หมด | รอเดือนใหม่ หรือเปลี่ยนแผน |
| แก้โค้ดแล้วบอทยังตอบแบบเดิม | Webhook ใช้โค้ดของเวอร์ชันที่ deploy ไว้ | Deploy > Manage deployments > ✏️ > Version: **New version** (URL คงเดิม) |
| ทดสอบผ่านหมดแต่ไม่มีแจ้งเตือนเลย | ยังไม่มีจุดความร้อนในรัศมี 500 ม. หรือยังไม่ได้ Run `installTriggers` | Run `previewAlert` และ `checkSetup` |

### วิธีดู log ใน Apps Script

- เปิดหน้า **Executions** จาก**ไอคอนเส้นสามขีดกับลูกศรเล่น (☰▷)** ที่แถบซ้าย (รูปนาฬิกาคือ Triggers ไม่ใช่ Executions)
- ทุกครั้งที่ LINE ส่งข้อความมาจะมีแถว `doPost` (ประเภท Web App) ส่วนการตรวจทุก 30 นาทีจะเป็นแถว `checkLandfillFireRisk` (ประเภท Time-driven)
- กดที่แถวเพื่อดู log ถ้ามีข้อผิดพลาดจะแสดงเป็นบรรทัดสีแดง

## ความปลอดภัย

- **เก็บ token ไว้ใน Script properties เท่านั้น** อย่าใส่ในโค้ด หน้าเว็บ หรือ GitHub
- **ถ้า token หลุด** (เช่น ติดในภาพหน้าจอ) ให้กด **Reissue** ทันที ถ้าระบบให้เลือกเวลาหมดอายุของ token เดิม ให้เลือกหมดอายุทันที แล้ววาง token ใหม่ใน Script properties มีผลทันทีโดยไม่ต้อง deploy ใหม่
- **Webhook URL เปิดให้ทุกคนเรียกได้** เพราะ LINE ต้องเรียกได้ แต่ Apps Script ตรวจลายเซ็น `X-Line-Signature` ของ LINE ไม่ได้ สคริปต์จึงทำได้อย่างเดียวคือตอบรหัสกลับด้วย replyToken และไม่เปลี่ยนการตั้งค่าใด ๆ จากคำขอทาง webhook
- **ส่งแจ้งเตือนเฉพาะรหัสที่อยู่ใน `LINE_TO`** ถ้าคนอื่นเชิญบอทเข้ากลุ่มของตัวเอง จะได้รหัสกลุ่มไป แต่จะไม่ได้รับแจ้งเตือนจนกว่าผู้ดูแลจะเพิ่มรหัสนั้น
- **ควรมีผู้ดูแลสำรอง:** เพิ่มผู้ดูแลร่วมใน LINE Official Account Manager และแชร์โปรเจกต์ Apps Script ให้ผู้รับผิดชอบสำรอง เพราะทริกเกอร์ทำงานในนามบัญชีผู้ติดตั้ง ถ้าบัญชีนั้นถูกปิด ระบบจะหยุด

## ข้อจำกัดที่ควรรู้

- **ความเร็ว:** ขึ้นกับรอบซิงก์ของระบบจุดความร้อนส่วนกลาง บวกรอบตรวจทุก 30 นาที การแจ้งเตือนจึงอาจมาช้ากว่าเวลาที่ดาวเทียมผ่านหลายชั่วโมง
- **ความแม่นยำ:** VIIRS ตรวจเป็นช่องกว้างราว 375 ม. จุดความร้อนในรัศมี 500 ม. จึงไม่ได้แปลว่าไฟไหม้บ่อขยะแน่นอน ต้องตรวจสอบในพื้นที่
- **ความครอบคลุม:** ดาวเทียมแต่ละดวงผ่านประเทศไทยราววันละ 2 ครั้ง (กลางวันและกลางคืน) ไฟที่เกิดแล้วดับระหว่างรอบ หรือมีเมฆบัง จะตรวจไม่พบ

## การดูแลหลังติดตั้ง

- ก่อนและระหว่างฤดูเผา ให้ Run `checkSetup` เป็นระยะเพื่อดูโควตาคงเหลือ
- เปลี่ยนกลุ่มรับแจ้งเตือน: หารหัสกลุ่มใหม่ตามขั้นที่ 7 แล้วแก้ `LINE_TO`
- หยุดชั่วคราวหรือเลิกใช้: Run `removeTriggers`
