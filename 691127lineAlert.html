A Satellite Alarm for Landfill Fires, Delivered to a LINE Group
Environmental officials in Nakhon Ratchasima have turned a map-based landfill fire radar into an alert that runs on its own every 30 minutes and messages a LINE group when a satellite spots heat within 500 meters of a waste site. Here is how it works, and how other agencies can set it up.
A mock-up of the alert the system posts to a LINE group, in Thai, when a satellite detects a hotspot within 500 meters of a waste disposal site. The site name, coordinates and group name are invented. Illustration by The Siam Times.

NAKHON RATCHASIMA — Fires at landfills tend to start small. Then they burrow into the waste, where they can smolder out of reach of water for days, sending up smoke long after the visible flames are gone. The sooner someone knows, the better the odds of putting one out while it is still small.

That is the thinking behind a new alert from the Environmental and Pollution Control Office 11, which covers Nakhon Ratchasima, Chaiyaphum, Buri Ram and Surin. Until now, the landfill fire radar on the Fire Radar map flagged danger only when someone opened the map. The new system keeps watch on its own, around the clock: when a satellite detects a hotspot within 500 meters of a waste disposal site, it posts a message to the officials’ LINE group. The system is now in trial use.

How it works

Every 30 minutes, a script running on Google Apps Script pulls the latest hotspots from NASA’s FIRMS service, detected by the VIIRS instrument on the NOAA-20 and NOAA-21 satellites, and checks them against the coordinates of more than 3,400 waste disposal sites in all 16 regional offices’ areas. It uses the same data and the same distance rule as the map, so what arrives on LINE matches what officials see on screen.

Each message gathers every site found in that round: its name, province and regional office, the number of hotspots, the closest distance and the time the satellite passed, with a Google Maps link for directions and a link back to the map. The system remembers what it has already reported, so the same hotspot is never sent twice, and a message that fails to go out is retried on the next round.

Many Thai agencies built their alerts on LINE Notify, but that service closed on March 31, 2025. The new alert uses the LINE Messaging API through a LINE Official Account instead. It takes more setup, but it costs nothing to run, because the script lives on Google’s free service.

Eight steps to set it up

An agency needs a LINE account, a Google account and the LINE group that will receive the alerts. The code is published in The Siam Times repository on GitHub, in apps-script/landfill-fire-line-alert.gs. Setup takes eight steps:

  1. Create a LINE Official Account at manager.line.biz and enable the Messaging API under Settings. Name the provider after your agency; it cannot be changed later.
  2. Issue a channel access token in the LINE Developers Console, on the Messaging API tab, and copy it with the copy icon beside it.
  3. Let the bot join groups by enabling “Allow bot to join group chats,” and turn off auto-reply messages.
  4. Install the script. Paste the code into a new Google Apps Script project, add the token as a script property named LINE_CHANNEL_ACCESS_TOKEN, then run checkSetup.
  5. Deploy it as a web app that executes as “Me,” with access for “Anyone.”
  6. Set the webhook. Paste the URL ending in /exec into the Webhook URL field, switch on “Use webhook” and leave “Webhook redelivery” off.
  7. Get the group ID. Invite the bot to the group and it replies with an ID beginning with C. Typing “group id” on its own in the group also works.
  8. Switch it on. Add the group ID as a script property named LINE_TO, run sendTestMessage, then run installTriggers so the script checks every 30 minutes.

Offices that only want their own area can add a property named ALERT_EPOS — 11 for EPO 11, for example — which also saves a large share of the message quota.

Lessons from a real installation

The trial installation turned up three problems that looked like a broken system but were only settings.

First, the bot left the group as soon as it was invited. A new LINE Official Account cannot join groups until “Allow bot to join group chats” is enabled. A group can also hold only one LINE Official Account at a time.

Second, the webhook’s Verify button reported an error, “302 Found.” That is normal for Google Apps Script, which answers with a redirect; the message still reaches the script, and the script runs.

Third, the bot stayed silent when asked for the group ID. Running checkSetup showed “HTTP 401,” meaning the token was wrong — typically because dragging to select it on a tablet copies only part of it, or because the shorter channel secret was pasted instead. The fix is to reissue the token, copy it with the copy icon and paste it over the old value.

When the cause is still unclear, the Executions page in Apps Script, marked by an icon of three lines and a play arrow, logs every message LINE sends as “doPost.” No entries at all usually means access was not set to “Anyone.” After any change to the code, the web app must be redeployed as a new version, or the bot keeps running the old one.

What it costs

The main cost is LINE’s message quota, which counts one message per recipient: a post to a 10-member group counts as 10. Replies with the group ID are free. The free plan in Thailand allows 300 messages a month, or about 30 alerts for a 10-member group, which may not last through the burning season from January to April.

The Basic plan costs 1,280 baht a month for 15,000 messages, and Pro costs 1,780 baht for 35,000, before value-added tax, as of November 2026. Running checkSetup shows how much of the quota is left.

Security and limits

The channel access token works like the bot’s password: anyone who has it can post as the bot. It belongs only in script properties, should never appear in a screenshot, and should be reissued at once if it leaks. Alerts go only to the IDs listed in LINE_TO, so someone who invites the bot to their own group receives nothing. Agencies should also name a backup administrator for both the LINE account and the Apps Script project, because the script runs under the Google account of whoever installed it.

An alert does not confirm a landfill fire. VIIRS measures heat in cells about 375 meters wide, so a hotspot within 500 meters may come from burning on neighboring land. Each satellite passes over Thailand about twice a day, so a fire that starts and dies between passes, or burns under cloud, goes unseen. And a message can arrive hours after the satellite passed, depending on when the central hotspot system syncs.

An alert, then, is a prompt to check the site, not proof of a fire. But learning within hours, rather than waiting for someone to open a map or for a report from the field, can mean reaching a landfill fire while it is still small.
